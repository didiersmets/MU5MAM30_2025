# Project 4 : Elimination tree and direct sparse Cholesky solver
### Anja Matic

This project implements a direct sparse Cholesky solver, applying it to solve the Navier-Stokes equation. 

### Build instructions

To build project run ./make. The excecutables are located in the folders 
- build/debug - debug build with assertion checks
- build/reslease - optimized builds

### Excecutables

#### test_symbolic 
Run tests of symblic phase of Cholesky factorization. 

##### Options 
- -s,  --subdiv (optional):  Number of mesh subdivisions used to construct sparsity pattern of the P1 matricies
- -p or --print  (optional): run in print mode to perform corectness check of algortihm.  Prints the sparsity pattern of  the P1 mass and stiffness matrix, the associated eilimination tree  and the sparsity pattern of the Cholesky factor. Print mode is inteded to be used with only a small number of subdivsions. If not provided, program will only print matrix statistics and nou complete matricies. 
##### Examples
- ./build/release/test_symbolic --print --subdiv 2 (run in print mode)
- ./build/release/test_symbolic -s 10 (run only benchmark tests)

#### test_cholesky
Runs tests fo sparse Cholesky factorization
##### Options 
- -c or --check (optional): Run corectness tests. If not provided, timing tests will be performed
- -s or --subdiv (optional): Number of mesh subdivisions used to construct sparsity pattern of the P1 matricies

##### Examples 
- ./build/release/test_cholesky --check --subdiv 2
- ./build/release/test_cholesky --subdiv 10

#### test_navier_stokes_cholesky

Navier Stokes solver, using Cholesky factorization as solution method. Code adapted from test_NS provided in class. Note that in this case the visosity \nu and the time-step size dt is fixed in the begining of the simulation. 

##### Options
- cube / sphere + n (obligatory): if the mesh should be cube or sphere and the number of subdivisions
- -b (optional): run code in benchmark mode, that is run and time one time step. If flag is not indicated code is run with GUI

##### Examples 
- ./build/release/test_navier_stokes_cholesky cube 10 - run tests with GUI
- t./build/release/test_navier_stokes_cholesky cube 10 -b - run benchmark tests

#### test_NS
 
Navier Stokes solver, using conjugate gradient as solution method. The code was provided in class and is just adapted to include benchmark tests

##### Options
- cube / sphere (obligatory): if the mesh should be cube or sphere
- b (optional): run code in benchmark mode, that is run and time one time step. If flag is not indicated code is run with GUI
##### Examples
- ./build/release/test_NS cube 10 - run tests with GUI
- ./build/release/test_NS cube 10 -b - run benchmark tests
